# DUP-015 — Use independent RNG streams for each stochastic sub-method

**Priority:** P1  
**Status:** Done (2026-03-01)

## Goal
Make reproducibility robust to code changes so that adding one stochastic feature does not perturb unrelated stochastic outputs.

## Scope
- Introduce a per-run root seed sequence.
- Spawn separate RNG streams for:
  - scope-level collision simulation
  - bucket-level collision simulation
  - position permutation
  - temporal permutation
  - any stratified or sidecar-specific simulation path
- Persist seed lineage in provenance tables.

## Failure modes and mitigations
- **Failure mode:** code reordering changes outputs even when inputs and seed are unchanged.  
  **Mitigation:** one spawned generator per sub-method.
- **Failure mode:** provenance loses the seed lineage needed to debug differences.  
  **Mitigation:** record seed family / sub-seed identifiers.

## Acceptance criteria
- Unrelated stochastic features no longer perturb each other’s results.
- Seed lineage is auditable.
- Golden fixtures remain stable under unrelated refactors.
