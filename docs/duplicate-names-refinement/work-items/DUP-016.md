# DUP-016 — Remove the current rounded hypergeometric approximation or replace it with direct finite-population sampling

**Priority:** P2  
**Status:** Done (2026-03-01)

## Goal
Eliminate approximation paths that distort the long tail and can create uncalibrated finite-population inference.

## Scope
Choose one of two paths:

**Option A — near-term correctness**
- disable inferential hypergeometric paths that rely on rounded probability-to-histogram reconstruction
- keep them expectation-only or unavailable

**Option B — full finite-population implementation**
- sample directly from integer per-key counts using a direct finite-population method
- return proper Monte Carlo quantiles and p-values

## Failure modes and mitigations
- **Failure mode:** rounded counts distort tail mass and occupancy structure.  
  **Mitigation:** do not expose that path as inferential.
- **Failure mode:** engineers keep a half-disabled branch alive.  
  **Mitigation:** explicit mode guards and tests.

## Acceptance criteria
- No inferential result depends on rounded probability-to-histogram reconstruction.
- Any remaining finite-population path has a documented and test-validated sampler.

## Verification
- Exact toy-case comparisons where enumeration is possible.
- Mode-guard regression tests.
- Simulation checks on long-tail cases.

## Implementation summary
- Chose **Option A (near-term correctness)**: keep rounded stratified-hypergeometric paths expectation-only and explicitly non-inferential.
- Added an explicit detector-level inferential guard reason:
  - `stratified_hypergeometric_rounding_inference_disabled`
- Implemented a scope inferential gate in `duplicates_exact`:
  - when `collision_baseline_model="hypergeometric"` and stratification is active with mixture probabilities, inferential status is forced to `unavailable` regardless of null-sample availability.
- This prevents future regressions where a partial/null hypergeometric simulation implementation could accidentally surface rounded-histogram hypergeometric inference as calibrated.
- Existing expectation outputs remain available; inferential fields stay suppressed (`p_value`, `z_score`, interval fields) under this guard.
