# DUP-014 — Replace the Monte Carlo draw-budget heuristic with precision-targeted simulation

**Priority:** P1  
**Status:** Done (2026-03-01)

## Goal
Make simulation effort depend on required numerical precision, not on a heuristic that can under-simulate exactly the cases where null distributions are most discrete.

## Scope
- Replace fixed `sqrt(n)`-style draw budgeting with sequential Monte Carlo.
- Stop when:
  - MCSE is below target, or
  - the confidence interval around `p` is clearly above/below the decision threshold
- Emit, at minimum:
  - `n_draws`
  - `mcse_p`
  - optional Monte Carlo confidence interval or resolution bound

## Failure modes and mitigations
- **Failure mode:** small hearings get too few draws and unstable p95/p99 bands.  
  **Mitigation:** higher minimum floor for quantiles and threshold-adjacent p-values.
- **Failure mode:** users treat coarse Monte Carlo p-values as exact.  
  **Mitigation:** expose draw count and precision metadata in outputs.

## Acceptance criteria
- Draw counts are no longer set by the current heuristic.
- Every MC-derived p-value/quantile includes precision metadata.
- Small hearings are not automatically under-simulated.

## Implementation summary
- Replaced `sqrt(n)`-scaled Monte Carlo draw budgeting in duplicates with precision-driven targeting:
  - scope/bucket draw ceilings are now capped by configured request/hard-cap, not row-count scaling.
  - simulation effort is driven by configured precision targets (`monte_carlo_target_p_mcse`, decision threshold/confidence, and minimum draw floor).
- Added sequential stopping support in null simulation when tail targets are known:
  - stop when MCSE target is met, or
  - stop when Wilson CI is clearly above/below the decision threshold.
- Added MC precision metadata for MC-derived summaries:
  - `monte_carlo_draws_effective`
  - `monte_carlo_quantile_resolution`
  - `monte_carlo_p_value_mcse`
  - `monte_carlo_p_value_ci_low`
  - `monte_carlo_p_value_ci_high`
- Propagated precision metadata through:
  - `duplicates_exact.collision_overview`
  - `duplicates_exact.collision_by_bucket`
  - report payload normalization for duplicate charts/tables
- Added analogous precision metadata for VRDB collision sidecar tail probabilities:
  - `tail_prob_pairs_mcse`
  - `tail_prob_pairs_ci_low`
  - `tail_prob_pairs_ci_high`
  - `monte_carlo_quantile_resolution`
- Preserved position-interval behavior by explicitly disabling precision early-stop for that interval path (keeps configured interval draw count behavior intact).
