# DUP-017 — Fix stratification endogeneity and propagate mixture-weight uncertainty

**Priority:** P2  
**Status:** Done (2026-03-01)

## Goal
Stop the stratified baseline from learning the answer from the same hearing it is supposed to test.

## Problem
If stratum weights are estimated from the hearing under test and then treated as fixed, the null can be shrunk toward the observed composition and p-values become too optimistic.

## Scope
Preferred fixes:
- estimate weights from historical hearings, or
- estimate from an independent matched-only subset when appropriate

If same-hearing estimation is unavoidable:
- use leave-one-name-out or cross-fitting for per-name tests

Also:
- propagate uncertainty in estimated weights through the null or use a conservative variance inflation approach

## Failure modes and mitigations
- **Failure mode:** same-hearing weight estimation leaks the tested name back into its own null.  
  **Mitigation:** LOO or cross-fitting.
- **Failure mode:** uncertainty in estimated weights disappears from inference.  
  **Mitigation:** sample or otherwise propagate weight uncertainty.

## Acceptance criteria
- No inferential stratified output uses same-hearing weights without leakage control.
- Stratified outputs include weight-provenance metadata.
- Weight uncertainty is either propagated or explicitly suppressed with descriptive-only status.

## Verification
- Unit tests for LOO/cross-fit behavior.
- Simulations comparing false-positive rates before/after the fix.
- Provenance-field tests.

## Implementation summary
- Implemented a near-term guard for stratification endogeneity in `duplicates_exact`:
  - when stratified mixture weights are estimated from same-hearing observed composition and no leakage control is applied, scope inference is forced to `descriptive_only`.
  - inferential reason: `stratification_endogeneity_uncontrolled`.
- Preserved prior `DUP-016` behavior for rounded stratified-hypergeometric paths:
  - those remain `unavailable` with reason `stratified_hypergeometric_rounding_inference_disabled`.
- Added stratification provenance metadata across duplicate outputs:
  - `stratification_weight_source` (`same_hearing_observed_counts` / `registry_global_fallback` / `none`)
  - `stratification_leakage_control` (`none` / `not_applicable`)
  - `stratification_weight_uncertainty` (`not_propagated` / `not_applicable`)
  - `stratification_endogeneity_uncontrolled` (boolean)
- Added provenance to:
  - `collision_methods`
  - `collision_stratification_sensitivity`
  - primary duplicate summary fields
  - report payload duplicate runtime normalization/records
- Chosen uncertainty policy for this ticket:
  - explicit suppression (`descriptive_only`) when endogeneity is uncontrolled, rather than attempting uncertainty propagation in this step.
