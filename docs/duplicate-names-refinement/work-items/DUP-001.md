# DUP-001 (Completed) — Define the statistical contract and report voice rules

**Priority:** P0  
**Status:** Done

## Goal
Lock the project to its intended purpose: produce public-facing anomaly signals from incomplete public sign-in data, without implying identity, intent, fraud, or certainty that the public dataset cannot support.

## What this work item covered
- Defined named evidence families instead of blending everything into one implied claim.
- Rewrote report language so results are framed as:
  - higher/lower than expected under a stated baseline;
  - signals for follow-up;
  - descriptive-only where inference is not supported.
- Added/standardized report terminology around:
  - duplicate **name-string collisions**
  - reference baselines
  - descriptive-only vs inferential outputs
- Set the interpretation rule that public data can screen for unusual patterns, but cannot prove same-person repetition.

## Done criteria
- No report text claims proof of repeated-person submissions.
- All user-facing outputs distinguish signal generation from identity or intent claims.
- The methodology/report language is aligned with public-data limitations.
