# DUP-020 — Build a hearing-relevant historical reference baseline and out-of-sample stratification path

**Priority:** P2  
**Status:** Done (2026-03-01)

## Goal
Move beyond a pure statewide registry reference by adding a better-aligned hearing-attendee reference model that is estimated out of sample.

## Scope
Build a historical baseline keyed by factors such as:
- committee
- chamber
- session/year
- topic cluster where practical

Requirements:
- the target hearing must be excluded from the training pool
- stratification weights must be estimated out of sample
- the VRDB baseline remains available as a comparator, not the only reference

## Failure modes and mitigations
- **Failure mode:** the model is trained on the target hearing and becomes partially self-referential.  
  **Mitigation:** leave-one-hearing-out or equivalent exclusion.
- **Failure mode:** historical baseline is treated as exact rather than overdispersed.  
  **Mitigation:** use an overdispersed predictive model and report provenance.

## Acceptance criteria
- Historical reference excludes the target hearing by construction.
- Stratification is estimated out of sample.
- The system can compare VRDB reference results with historical-hearing reference results.

## Verification
- Data-lineage tests for exclusion.
- Backtests comparing VRDB-only vs historical reference behavior.
- Provenance tests for baseline source labeling.
